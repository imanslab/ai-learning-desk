## کارت‌ها چطور کار می‌کنند

روی هر کارت یک پرسش است. روی آن کلیک کنید تا برگردد. پشت کارت چهار بخش دارد:

- ایده: مفهوم چیست، در یک یا دو جمله.
- روش: چطور از آن استفاده می‌کنید.
- ارتباط: یک مثال.
- مراقب باشید: رایج‌ترین اشتباه.

بعضی کارت‌ها یک بخش «در یک نفس بگویید» هم دارند، که پاسخی کوتاه برای گفتن است.

می‌توانید جستجو کنید، بر اساس موضوع فیلتر کنید، کارت‌ها را بُر بزنید و کارت‌های یادگرفته را علامت بزنید. پیشرفت شما فقط در مرورگر خودتان ذخیره می‌شود.
