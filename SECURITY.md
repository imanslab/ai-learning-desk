# Security policy

[فارسی](SECURITY.fa.md) | **English**

> [Read this in Persian](SECURITY.fa.md). That translation is informational.

## What this site is

A static page. It has no server code, no accounts, no forms, no cookies and no
analytics. It saves your progress in your own browser and sends nothing
anywhere.

## Reporting a problem

Report privately, through the contact on the author's GitHub profile,
https://github.com/Iman. Do not open a public issue for a security problem.

Include what you did, what happened, and what you expected. A way to reproduce
it is worth more than a description.

## What counts

A way to run script in a visitor's browser through the page or the card data.
A link on a card that leads somewhere malicious. Anything that makes the page
send data somewhere.

## What does not count

Progress saved in your own browser's storage. Anyone with access to your
browser can read it, and it holds only the ids of the cards you marked.

## What this project promises back

An acknowledgement, an honest assessment, and credit if you want it. There is
no bounty.
