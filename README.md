# AI Learning Desk

A study page of 286 flash cards on machine learning, deep learning, reinforcement learning, language models and AI systems in production.

Open the site: https://imanslab.github.io/ai-learning-desk/

## How the cards work

Each card starts with a question. Click it to turn it over. The back has four parts:

- The idea: what the concept is, in one or two sentences.
- The technique: how you use it.
- Connect it: one example.
- Watch for: the most common mistake.

Some cards also have "Say it in one breath", a short spoken answer.

You can search, filter by topic, shuffle, and mark cards as learned. Progress is saved in your browser only.

## Run it on your computer

The site is three static files and a data file. There is no build step.

```sh
git clone https://github.com/imanslab/ai-learning-desk.git
cd ai-learning-desk
python3 -m http.server 8000
```

Then open http://localhost:8000 in a browser. Opening index.html directly from the file system also works.

## Sources

Cards with a link point to the original paper or the official documentation. Cards marked "Author's study notes" or "Author's research notes" come from the author's own notes. Check the linked source before you rely on a card.
